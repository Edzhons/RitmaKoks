# RitmaKoks frontend

The RitmaKoks frontend is a Vue 3 single-page application built with Vite, Vue Router, Pinia, Bootstrap 5, and custom responsive styles.

## Run locally

```powershell
npm install
npm run dev
```

## Check the frontend

```powershell
npm run build
npm run test:unit -- --run
npm exec eslint -- .
```

The initial UI foundation includes responsive navigation, reusable studio cards, and a light/dark theme preference saved in the browser. The editor, authentication, and library features will be added in later roadmap steps.
